Privacy & Terms

Overview

In short Crimstone keeps no personal information about you. The only thing it stores is a Discord ID paired with a number, your XP, plus whatever settings your server's admins choose. Nothing is sold, and you can have your record deleted by asking.

Not covered Discord itself, which has its own privacy policy, and any other site you reach through a link here

What Crimstone Stores

Server records Server ID, prefix, chosen channels and roles, and which features are switched on. Set by admins when the bot joins.
Member records Your user ID, the server ID, your XP, your level, and the timestamp of your last counted message. XP comes from the fact that you sent a message, not from what it said.
That is all There is no other database. Nothing else you do with Crimstone is written down.

What Crimstone Never Stores

Messages Message content is read in memory to award XP and detect commands, then discarded. It is never written to disk.
DMs Direct messages between you and anyone else
Media Voice audio, attachments, images, or files
Identity Your email address, phone number, real name, or address
Payments Crimstone takes no payments and stores no payment details
Network Your IP address or device information
Mod actions Commands such as /ban act through Discord and are not logged by the bot. Discord keeps its own audit log.
Command input Text you type into a slash command is used to answer you, then gone
Elsewhere Anything at all from servers Crimstone has not been invited to

Why It Is Stored

Features A leveling system cannot show your level without recording it
Settings Server configuration has to survive restarts
Anti-abuse Cooldown timestamps stop XP farming and command spam
Never for Advertising, profiling, training machine learning models, or anything unrelated to running the bot

Where It Lives

Hosting Self-Hosted.
Access Limited to the bot operator, over authenticated connections
Security Reasonable steps are taken, but no service can promise perfect security. Do not put sensitive information into the bot. If a breach affects your data, notice goes up in the support server and on this site as fast as the facts allow.

How Long It Is Kept

Server records Deleted within [30 days] of Crimstone being removed from that server
Member records Kept while you are in a server that uses Crimstone, and deleted on request at any time
Everything else Not kept in the first place, so there is nothing to expire

Who Else Sees It

Not sold Crimstone's data is never sold, rented, or traded. It is shared only in the cases below.
Discord Everything the bot does travels over Discord's API, because that is how bots work
The host The provider operating the machine the data sits on
Your server Leaderboards and rank cards are public by design, so anything shown in a channel is visible to whoever can read it
Bot lists Sites such as top.gg receive only totals like server count. No individual data is sent.
The law If a valid legal request requires disclosure

Your Choices

How to ask Message the operator by email or in the support server, with your Discord user ID and the server it concerns. No charge, no reason needed, handled within [30 days].
See your data Ask for a copy of everything Crimstone holds about you, and it will be sent back to you
Delete it Ask for your records to be erased. Deletion is permanent, so XP and levels cannot be restored afterwards, and using tracked features again starts a new record.
Fix it Ask for anything inaccurate to be corrected
Legal rights You may have further rights under the UK and EU GDPR or the California Consumer Privacy Act. They are honoured regardless of where you live. Where the GDPR applies, the lawful basis is legitimate interest: running a bot a server chose to install.
