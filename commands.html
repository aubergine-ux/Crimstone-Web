Commands

All 61 of Crimstone's slash commands. Type /help in Discord for details on any of them.

Moderation (14)

/ban Ban a User from the Server
/unban Lift a Ban from a User
/kick Kick a User from the Server
/timeout Timeout a User for a Set Duration
/purge Delete Multiple Messages at Once
/slowmode Set Slowmode for a Channel
/nickname Change or Reset a User's Nickname
/role-give Give a Role to a User
/role-remove Remove a Role from a User
/role-search List Every Member with a Role
/warn Warn a User
/unwarn Remove a Warning from a User
/warnings View a User's Warnings
/modstats View a Member's Moderation History

Leveling (6)

/rankcard Customize Your Rank Card
